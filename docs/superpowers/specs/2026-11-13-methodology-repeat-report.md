# Methodology and allele repeat reporting

User-approved scope: explain every current input, show methodology on the homepage, keep method/group comparisons visible, and include estimated repeat number for each normal, expanded and intermediate target. Existing EI, peak selection, source data, target identity and formal eligibility must not change. Existing authorization covers implementation and updating the public Beta; no new confirmation is needed.

Derive repeat count once per acquisition/allele from its current fitted modal and the selected localization mapping: (modal bp − intercept) / slope. Report the mapping, counting definition and supplied CE margin, with an explicit unavailable reason when prerequisites fail. Unknown uncertainty stays unknown; a propagated CE margin is not a confidence interval. Preserve input repeat evidence in separate columns. Never infer a missing second allele or relabel an allele from the new estimate.

Use the current quiet monochrome interface. Method explanations must match the frozen implementation, including adaptive anchored regression and Bayesian frozen seed posterior predictive assignment. Both methods use the same height-weighted EI formula. Provide a complete Chinese input guide and retain the same public deployment URL.
