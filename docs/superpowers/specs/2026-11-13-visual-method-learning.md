# Visual method learning and field help

Authorized request: add small question-mark help beside every input, with meaning, units and examples, and explicit required/optional/conditional labels. Replace prose-heavy homepage methodology with textbook-style mathematical typesetting, equations before symbol definitions, and explanatory animations. Preserve the quiet black/white/teal/purple style and all calculation logic/data. Prior permission to implement and deploy without questions remains in force.

Design decision: native MathML provides real fractions, sums, subscripts and aligned posterior equations without external math dependencies. Three method tabs (EI, Adaptive, Bayesian) each pair equations and brief symbol definitions with a controllable native SVG animation. A clearly labelled synthetic trace comes from the unchanged R methods, not browser-side refitting or uploaded user data. Animations start paused, support play/pause, step/back/replay, keyboard navigation, and reduced motion. Bayesian posterior details may expand; essential equation/definitions are always visible in its tab.

Field help: a compact requirement badge and focusable ? button next to the original label; hover/focus/click opens a viewport-contained popover with meaning/unit/example and the requirement condition. Escape/outside click dismiss; help never toggles checkboxes or changes values. Dynamic Shiny inputs, modals, table-editor column headers and dashboard selectors receive the same help. Existing validation and bindings remain unchanged. The full Chinese guide remains available.
