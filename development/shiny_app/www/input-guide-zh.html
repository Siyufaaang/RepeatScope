先分清三个量

量含义
Size / modal size，bpCE sizing 给出的片段长度。Modal 是当前目标 allele 的锚定峰；不是整个孔所有信号中随意选出的最大峰。
Estimated repeat number用当前 allele 的 modal 长度，经过已选定的参考结构换算或实测 CE 校准得到的重复数估计。Normal、expanded、intermediate 分别按各自目标记录报告。不是 EI，也不是测序确认的整数重复数。
Expansion index，EI所选峰相对 modal 的 repeat-step 距离，按各峰自身 Height 加权的平均值。Modal 的相对距离为 0。EI 描述所选右侧尾峰，不是 allele 总重复数。

一个 Well 可以包含多个 acquisition，每个 acquisition 又可以有多个 allele target。重复数和 EI 都必须保留这些身份。软件不会为了凑齐 normal / expanded 两列而虚构没有识别到的第二个 allele。

All samples / Missing genotype / All wells / Clear selection 是选择快捷键。Undo 撤回已保存的板图编辑；Discard unapplied edits 清除还未提交的表单草稿。

Reference typeGenomic 或 Transcript；应与引物和模板对应，不能视为可随意互换。

Explicit accession.version已知参考时直接填写带版本后缀的 accession，以保证复现同一参考序列。
Optional interval start / end原 accession 上 1-based、两端都包含的坐标。指定区间时两端一起填；两端留空请求支持的整条记录。

Offline FASTA / Or paste FASTA替代在线检索的单条核酸 FASTA，含 >header 和序列。选择的上传文件优先于粘贴文本。
Forward primer / Reverse primer分别输入真实使用的 5′→3′ 引物序列，包括确实存在的尾序列；Reverse 也按实际订购方向填写。软件处理反向互补匹配。
Reported motif例如 CAG，用于重复结构候选搜索和展示；填写 motif 本身，不写 (CAG)23。
Forward / Reverse non-binding 5′ tail填写已经包含在上述完整引物前端、但不与参考结合的 5′ 尾。软件用结合部分匹配参考，并将尾长度计入产物长度。不要在完整引物之外重复加一遍。
Dye label荧光标记名称等元数据；不是 DNA 碱基，不作为长度计数。
Counted tract start / end在当前定向参考序列上的、1-based 且两端包含的计数区间。不是 CE 峰长，也不是原 accession 坐标的任意复制。必须结合结构图、显示的序列和方向核对。
Counting ruleEntire bounded tract：将该边界内的 tract 长度计入，包括声明的 interruptions；Motif units：只计 motif 单元，被排除的 interruption 长度进入 fixed length。选择会改变参考换算的计数定义。
Locus counting definition / source说明该位点“一个 repeat”以及 interruption 如何计数，写明 SOP / 文献依据。
Boundary confirmation or adjustment reason记录为何接受或调整这对边界。Confirm with evidence 才是正式结构确认，自动预览不是证据确认。

Match primers now 得到参考扩增产物与计数结构。参考上的 repeat count 不是患者样本 repeat count；此匹配也不等于全基因组引物特异性验证。

Analysis setup：过滤、范围与长度换算

输入怎么填写 / 有什么影响
Minimum candidate size (bp)候选峰最小片段长度；低于它的峰不参与该分析。不是 normal / expanded 的 repeat cutoff。
Peak channel与导入表完全一致的目标通道标签，例如 B；若明确要全部通道，输入 ALL。B 不是所有实验通用默认。
Assay / primer-set name当前实验 / 引物组名称，用来标明这套范围和校准属于哪个 assay。
Counted repeat definition此报告 repeat number 的具体定义，包括 interruptions 如何处理；要与参考结构和校准一致。
bp per counted repeat一个被计数 repeat 的碱基长度，例如 CAG 为 3。理论参考换算中作为 slope；它与实测 CE slope 是相关但不同的参数。
Normal upper bound / Expanded lower bound正常上界和 expanded 下界，单位是 repeats。中间空档保留 intermediate / uncertain；不同位点与 assay 应用其对应的有来源定义。
Include normal upper / expanded lower bound控制等于边界时归入该范围，还是排除该边界。两项独立，不应凭感觉选择。
Range source / version重复数范围的文献、实验 SOP 或 profile 版本。Reset to gene defaults 会恢复基因 profile，应检查是否覆盖自己的定制值。
Length conversionFrom matched reference / primers：使用参考结构 fixed length 和 repeat 单位；Measured linear CE calibration：使用你提供的实测线性校准。理论长度不等于实测迁移率校准。
CE intercept (bp)线性校准 Size = intercept + slope × repeats 的截距。不是任意调到“符合旧结果”的修正值。
CE slope (bp / repeat)每增加一个 repeat，CE 测得片段长度增加多少 bp；必须大于 0。不要未经校准就将理论 3 bp 当成实测斜率的证据。
CE uncertainty ± bp已知的 CE 长度误差 / margin，用于检查边界和换算范围。留空表示未知；0 是明确的零 margin 假设，不能代表“我不知道”。不是 EI 置信区间。
Mapping / uncertainty basis校准和 uncertainty 的来源、标准样本或验证记录。新报告会带上此依据。

Apply filter 提交候选过滤；Apply analysis setup 提交范围与换算。更改这些输入后重新 Calculate EI，避免把旧 modal、旧分配和新校准拼在一起。

Adaptive 与 Bayesian 的实际计算

两者共用当前 target 的 modal，先从候选峰中排除 Height < 0.03×modal Height 的低峰，再校准和选峰。恰好 3% 的峰保留。被排除的低峰不影响 Adaptive 间距、Bayesian seeds 或 ambiguity；原始峰表仍保留供查看，缺失的 repeat index 不重新连续编号。

结果页的 Height threshold 是对已分配峰的额外 EI 筛选，不重新拟合；设为低于 3% 也不能恢复已被选峰下限排除的峰。两者采用同一个最终 EI 公式，区别在于哪些合格的 physical peaks 被分配到相对 repeat step k。旧版本保存的拟合结果需 Calculate EI 重新计算。

EI = Σ(Hₖ × k) / ΣHₖ；modal k=0；纳入峰须 Hₖ ≥ p×Hmodal，并位于所选窗口。

Adaptive：从 modal m 和 nominal spacing s 开始，依次预测 m+k×s。容差内取最高的未用峰，高度相同时取更接近期望位置者，再取较小 Size；没有候选则跳过该 step。每次接受后，以所有已接受的非 modal 峰计算 s=Σ[kᵢ(Sizeᵢ−m)]/Σkᵢ²，约束在 spacing bounds 内，继续向右。最后应用报告阈值与窗口。

Bayesian：模型为 yᵢ=Sizeᵢ−m=kᵢs+εᵢ，使用 Normal–Inverse-Gamma 先验。当前 adapter 的 seed_predictive=1，前几个 seed 通过顺序预测窗口校准，默认至少 3、最多 5。seed 要满足高度 floor，并在有竞争峰时达到 3 倍优势；缺失、太弱、竞争无法排除或窗口过宽会停止校准。随后冻结仅由已接受 seed 得到的 posterior，以 Student-t 点预测区间为后续 k 找唯一候选。多个候选、跨窗口物理峰重叠或窗口过宽保留 unresolved；影响当前 EI 范围的 unresolved 会导致 unavailable，而不是给一个静默不完整的数字。

κ=κ₀+Σkᵢ²；μ=(κ₀μ₀+Σkᵢyᵢ)/κ；α=α₀+n/2
β=β₀+½Σ(yᵢ−kᵢμ)²+½κ₀(μ−μ₀)²
预测中心=m+kμ；scale=√[(β/α)(1+k²/κ)]；自由度=2α。

默认 μ₀ 为 nominal spacing，κ₀=0.05、α₀=2、β₀=0.01，双侧 predictive coverage=95%。这里不是按“真峰概率”给 EI 加权；最后仍使用每个入选峰自身 Height。默认搜索 support 为 min(观察到的最大候选 Size, max(modal+33bp, modal 右侧≥3%峰的最右 Size+1.5bp))，拟合后冻结。更改最终报告阈值不会改变 support。

Estimated repeat number = (modal bp − intercept bp) / slope(bp/repeat)
CE margin：[(modal−u−intercept)/slope, (modal+u−intercept)/slope]

u 为用户提供的 CE ±bp margin。区间只传播这部分误差，不包含校准斜率 / 截距本身的不确定性，不称为置信区间。导出保留非整数估计值，不擅自四舍五入成测序计数。如果 nominal count 与既有类别不一致，应复核校准、计数定义、target 和证据，软件不会自动篡改类别。
